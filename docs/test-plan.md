# OrangeHRM UI Automation Test Plan

## Objective
Validate critical user journeys and core modules of the OrangeHRM demo through maintainable UI automation.

## Scope
- Authentication
- Dashboard
- Navigation
- PIM / Employee Management
- Leave
- Admin / User Management
- Recruitment
- Time
- Logout

## Test Types
- Functional
- Negative
- Smoke
- Regression
- Validation
- Navigation

## Out of Scope
- Performance testing
- Security penetration testing
- Production data validation

## Environment
- Browser: Chrome
- Runtime: Node.js
- Automation: Selenium WebDriver
- Test runner: Mocha
- Assertion: Chai

## Entry Criteria
- Application is reachable
- Demo credentials are available
- Dependencies installed

## Exit Criteria
- Critical smoke scenarios pass
- Regression execution is completed
- Failed tests are reviewed with evidence

## Risks
The application is a public demo environment and may change or become temporarily unavailable.
